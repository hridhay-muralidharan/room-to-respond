# Lived-to-constructed journey

## Sequence

1. **Lived moment:** the user records a moment from their life in their own words.
2. **Deepening:** optional prompts capture felt experience, thought, speech, action, want, consequence, and present meaning.
3. **Model review:** the agent offers tentative, evidence-linked observations and one open tension.
4. **Probe selection:** the agent identifies an unexplored dimension or uncertainty and explains why it matters.
5. **Constructed situation:** the user responds to a bounded variation in text; voice is a future input mode.
6. **Transfer:** the user compares the constructed response to the lived moment.
7. **Revision:** the user decides what to keep, qualify, reject, or leave unresolved.

## Probe strategies

- change a condition such as time, support, information, or perceived consequence;
- reverse who holds responsibility or bears the cost;
- explore a need or value not yet represented;
- test an alternative interpretation;
- transfer a pattern to a lower-stakes domain;
- revisit an unresolved tension without forcing a decision.

Prompts must be original, culturally inclusive, non-leading, psychologically bounded, and clearly labelled as constructed.
